01. Brief and permissions [brief]

02. Faces and identity [identity]
Compare each face at the same zoom: age, facial proportions, eyes, mouth and distinctive marks.
Hold any unintended identity change.

03. Skin texture [skin]
Inspect forehead, cheeks and neck for waxy smoothing, patchy colour, repeated texture and lost pores.
Rework visible texture loss outside the agreed finish.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

04. Hair and fine edges [hair]
Compare flyaways, hairline, eyelashes, veil edges and fine fur against light and dark backgrounds.
Rework halos, missing strands and cut-out edges.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

05. Hands and anatomy [hands]
Count fingers; inspect joints, limb boundaries, feet and overlapping subjects.
Hold added, missing or malformed anatomy.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

06. Garment construction [garment]
Compare neckline, sleeves, hem, seams, fasteners, lace and folds with the source.
Hold changes to product construction or fit claims.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

07. Prints and branding [pattern]
Check plaid continuity, embroidery, labels, lettering and logo placement.
Hold altered branding, illegible labels or invented pattern details.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

08. Material and surface [material]
Review leather grain, satin sheen, suede nap, metal and stone facets. Do not mistake stronger highlights for accurate material.
Hold misleading product properties; rework accidental texture loss.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

09. Jewelry geometry [jewelry]
Inspect prongs, engraving, stone count and shape, band thickness and reflections at equal scale.
Hold changed construction, added stones or misleading gemstone appearance.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

10. Colour consistency [colour]
Compare to an agreed reference on the same colour-managed display; check white balance and product hue across the batch.
Escalate colour-critical uncertainty; do not invent numerical tolerances.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

11. Background and objects [background]
Check for invented or missing objects, warped architecture and mismatched horizons.
Hold undisclosed scene changes outside the brief.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

12. Shadows and grounding [shadows]
Check contact shadows, direction, softness and reflections. Confirm that products and feet sit on the surface.
Rework floating products or inconsistent light.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

13. Crop and geometry [crop]
Align source and output where framing should be retained. Inspect stretch, scale, rotation and perspective.
Hold an unapproved crop or geometry change.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

14. Local edit boundaries [detail]
Inspect the boundary around each requested edit at 100% and at intended viewing size.
Rework seams, blur patches and repeated cloned texture.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

15. File and resolution [resolution]
Open exported files; verify actual pixel dimensions, format, colour profile, orientation and agreed watermark state.
Hold unreadable files or a delivery format that misses the brief.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

16. Batch consistency [batch]
Review a contact sheet, then inspect each critical item individually. Cover every lighting condition, material, pose and processing variant.
Expand review when a sampled defect suggests a repeated failure.
Decision: ____  Evidence / file IDs: ____  Owner / due: ____

17. Revisions and traceability [revision]
Record input ID, output version, requested change, reviewer, decision and evidence crop. Recheck corrected files.
Hold unresolved critical issues; do not overwrite the audit trail.

18. Delivery approval [approval]
Confirm agreed scope, all critical checks, outstanding rework and the approving person.
Release only explicitly approved versions; an average score cannot override a critical failure.
