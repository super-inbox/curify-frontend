# Fashion history prompt-gallery content drop · 2026-10-29

Adds **15 original AI fashion images**, IDs **4415–4429**, to `public/data/nanobanana.json`. This is a prompt-gallery drop using the existing editorial importer, not a new template family. Three groups: selected British/French fashion inspirations (1900–2000), selected European formalwear (1550–1950), and British white-bridalwear inspirations (1920–2020).

## Generation and reuse

The images were generated with built-in imagegen using authored prompts. The 1900 frame established an original adult character and studio composition; fourteen subsequent wardrobe variations referenced that image. They were not generated by an existing Curify template. These are AI style interpretations, not archival evidence, museum reconstructions, client work or verified replicas of named designers.

`scripts/configs/fashion_history_2026_10_29.json` contains titles, descriptions, curated tags, English/Chinese aliases, source SHA-256 hashes and CDN destinations. Public `promptText` values are **adapted reusable instructions**, reconstructed from the saved production specification, not verbatim tool transcripts. They include a self-contained character/lighting description and explain when a user-supplied character reference is needed. Text alone does not guarantee the example identity. `referenceSourceFile` records which source frame was used in the original production.

The original source images remain in sibling Gallery:
`cultural_videos/costume_tryon/2026-10-29-fashion-through-time/frames/`.
The original video batch, detailed source notes and normalized image prompt specification are in Gallery:
`smm_daily/2026-09-10-fb-souvenir-video/2026-10-29-fashion-through-time/`.

No original video, platform caption, publishing state, template definition or translation file is modified in this frontend commit.
