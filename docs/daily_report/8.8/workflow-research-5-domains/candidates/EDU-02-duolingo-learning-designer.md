## What was actually observed (EXTERNAL_SOURCE_CONFIRMED)

- **Brief:** Three-day at-home assignment for Duolingo's Learning Designer Internship: "Teaching Language Patterns to Beginners," specifically noun-adjective gender agreement. EXTERNAL_SOURCE_CONFIRMED.
- **Pedagogical process/rationale:**
  - Scaffolding: gender introduced via proper nouns before common nouns, accounting for learners whose native languages lack grammatical gender. EXTERNAL_SOURCE_CONFIRMED.
  - Signaling: blue/pink color-coding for masculine/feminine, leveraging "globally understood" cultural associations. EXTERNAL_SOURCE_CONFIRMED.
  - Cognitive-load management: nouns held static across slides to avoid overload. EXTERNAL_SOURCE_CONFIRMED.
  - Schema-building: reiteration across multiple screens to cement noun-adjective relationships. EXTERNAL_SOURCE_CONFIRMED.
- **Learning assets:** Six sequential instructional screens progressing from gender introduction to adjective-noun agreement, using consistent color signals and limited text (aligned with Duolingo's "byte-size learning content" philosophy). EXTERNAL_SOURCE_CONFIRMED.
- **Testing/evaluation:** None presented — the case study itself was the evaluation artifact used in Duolingo's internship selection process, not a shipped/tested product. EXTERNAL_SOURCE_CONFIRMED.
