# Jewelry gallery import · 2026-10-23

Five original concept images generated with built-in image_gen, imported as examples under existing `template-ecommerce-product-photography`. No new template was created; this association is for gallery discovery and remix, not a claim that the original images were generated by the template pipeline.

Raw PNGs and SHA-256 hashes: `curify-gallery/daily_inspirations/Oct_23_jewelry/manifest.json`. Exact prompts, reference dependencies and bilingual titles are mirrored in `scripts/configs/jewelry_gallery_import_2026-10-23.json` (an import manifest, not a batch-generation config). The `product` parameter carries the detailed scene prompt for remix. Reference-dependent output identity is not guaranteed without supplying the reference image.

Ingested using `scripts/sync_nano_inspiration.cjs --source=<gallery>/daily_inspirations/Oct_23_jewelry`; this creates watermarked full images and 512px previews. Auto-tag had no API key in the isolated checkout, so topics, tags and bilingual aliases were curated manually for all five records. Existing template fields and translations were unchanged.

Only the ten new full/preview assets are uploaded to their corresponding `gs://curify-static/images/nano_insp/` and `nano_insp_preview/` paths. Assets follow this repository's CDN-only convention (`public/images/` is ignored); the raw originals are versioned in curify-gallery. Portfolio and index are versioned separately in `curify-gtm/curify_portfolios`.

The external jewelry references and fruit detail-page examples are excluded. Gold/silver describe color; no purity, gemstone grade, certification or client-sales claim is made.
